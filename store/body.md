ISO・プライバシーマーク・HACCP・エコアクション21 などの認証では、**自社に当てはまる法令を洗い出し、守れているかを毎年確かめる**ことが求められます。その一覧が「法令チェックシート」（法規制登録簿・法令遵守評価表とも呼ばれます）です。

困るのは、どの法令が当てはまるかが業務の内容や設備で変わることです。それを判断するのに何を調べればよいかが、担当者にも分かりにくい。このシステムは、そこを**AIの聞き取り**で埋めます。

■ 使い方

1. ジャンルを選ぶ（いくつでも一緒に選べます）。所在地を選ぶと、その地域の条例も入ります
2. 「インタビュー開始」を押すと、AIが1問ずつ聞きます。ボタンで選んでも、文章で答えても構いません（「ラーメン屋をやってます。お土産用の餃子も作って売ってます」→「飲食店」「製造・加工」）
3. 答え終わると、当てはまる項目だけが並んだチェックシートができます。法令名と条番号、やること、頻度、確かめ方、残す記録、当てはまった理由
4. Excel に保存して、確認日・担当・結果を書き込めます。回答をファイルに保存しておけば、翌年は変わったところだけ答え直せます

「わからない」と答えた質問に関係する項目は、消さずに**要確認**として残します。見落としを作らないためです。

■ AIに法令を作らせません

チェック項目は、人が e-Gov法令検索（デジタル庁）の条文で確かめて入れたデータからだけ出します。公開の前に、全項目について「条番号が実在するか」「項目に書いた語が条文の本文にあるか」を機械で突き合わせています。改正で条文が動けば、ここで落ちます。

AIがするのは、文章で書かれた答えを選択肢に直すことと、「この質問はどういう意味？」と聞き返されたときの説明だけです。

■ 収録しているジャンル

- **情報・個人情報（ISO/IEC 27001・プライバシーマーク）** … 質問18問・項目35件。個人情報保護法と施行規則（利用目的・安全管理措置・委託先の監督・漏えい等の報告・第三者提供の記録・外国にある第三者への提供・開示請求）、マイナンバー法、特定電子メール法、不正アクセス禁止法、不正競争防止法（営業秘密）、電子帳簿保存法、著作権法、労働安全衛生法（健康情報）、個人情報保護委員会のガイドライン
- **食品衛生（HACCP・JFS・FSSC 22000）** … 質問16問・項目35件。食品衛生法と施行令・施行規則（HACCPの衛生管理計画・小規模な営業者の手引書・営業許可と届出・自主回収・器具容器包装のポジティブリスト）、食品表示法と食品表示基準、計量法、水道法（受水槽）、食品リサイクル法、廃棄物処理法、健康増進法（喫煙）、名古屋市の営業許可・食品衛生責任者

環境（エコアクション21・ISO 14001）や労働安全衛生（ISO 45001）は、データのファイルを1つ足すだけで増やせます。追加の作成もお受けします。

■ 自分のサーバーに置けます

PHP 1ファイルとデータ（JSON）1本だけです。データベースサーバーも常駐プロセスも要りません。

**インタビューの答えはブラウザの中だけで扱い、サーバーには残しません。** 工場の設備や扱う情報は、外に出したくない会社が多いからです。AIに送るのは、文章で答えたときのその1問の答えだけで、AIの口（OpenAI 互換）は設定ファイルで自社のものに向けられます。設定しなければ、選択肢を押して答える形でAIなしに動きます。

■ 置き方

1. index.php・.htaccess・klawnavi_data/ を置く
2. AIを使うなら klawnavi_config.sample.php を klawnavi_config.php にして、AIの口とキーを書く
3. ブラウザで開く

PHP 8（curl）だけで動きます。

■ データを新しくする

```
python3 scripts/fetch_law.py      # e-Gov法令検索から条文を取る
python3 scripts/verify_law.py     # 全項目を条文と突き合わせる（落ちたら公開しない）
python3 scripts/build_data.py     # 画面が読む data.json を作る
python3 scripts/selftest.py URL   # ブラウザで最後まで通して、スマホ幅のはみ出しも見る
```

■ しないこと

- 当てはまるかどうかの最終的な判断はしません。チェックシートは遵守状況を確かめるための**たたき台**です
- 罰則や金額など、条文で確かめていないことは書いていません
